# 📁 File Explorer - React Application

A modern, interactive file explorer built with React that allows users to browse, create, edit, rename, and delete files and folders with a clean user interface.

![File Explorer](https://img.shields.io/badge/React-19.2.0-blue)
![Tailwind CSS](https://img.shields.io/badge/TailwindCSS-3.4.0-38bdf8)
![License](https://img.shields.io/badge/License-MIT-green)

## 🌟 Features

- ✅ **Browse Files & Folders**: Navigate through a hierarchical file structure
- ✅ **Create**: Add new files and folders
- ✅ **Rename**: Edit file and folder names
- ✅ **Delete**: Remove files and folders
- ✅ **Copy/Paste**: Duplicate files and folders
- ✅ **Search**: Find files and folders quickly
- ✅ **Drag & Drop**: Move files and folders
- ✅ **Responsive Design**: Works on all screen sizes

## 🛠️ Technologies Used

- **React** (v19.2.0) - UI framework
- **Tailwind CSS** (v3.4.0) - Styling
- **Lucide React** - Icons
- **React DnD** - Drag and drop functionality
- **React Testing Library** - Testing
