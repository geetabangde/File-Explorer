# File Explorer - React Application

A modern and interactive File Explorer built using React, featuring folder navigation, file management, search, and drag-and-drop functionality.

## Features

-  **Browse Files & Folders**: Navigate through a hierarchical file structure
-  **Create**: Add new files and folders
-  **Rename**: Edit file and folder names
-  **Delete**: Remove files and folders
-  **Copy/Paste**: Duplicate files and folders
-  **Search**: Find files and folders quickly
-  **Drag & Drop**: Move files and folders
-  **Responsive Design**: Works on all screen sizes

##  Technologies Used

- **React** (v24.10.0) - UI framework
- **Tailwind C00** (v3.4.18) - Styling
- **Lucide React** - Icons
- **React DnD** - Drag and drop functionality
- **React Testing Library** - Testing

##  Installation
1.Clone the repository:
git clone https://github.com/geetabangde/File-Explorer.git

2.Go to the project folder:
cd File-Explorer

3.Install dependencies:
npm install

4.Start the project:
npm start
